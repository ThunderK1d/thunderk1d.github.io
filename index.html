AutoPoster

A personal desktop tool that publishes the owner's own videos to their own YouTube, TikTok and Instagram accounts, using the same title and description everywhere.

What it does

  • Runs locally on the owner's Windows computer. There is no server and no web service.
  • Takes a video file and a text file with its title and description from a local folder.
  • Uploads the video through the official APIs: YouTube Data API v3, TikTok Content Posting API and Instagram API with Instagram Login.
  • Is used only by its owner to post to accounts the owner controls. It is not offered to the public.
